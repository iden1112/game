# 훈련장 1v1 — Godot 버전

웹 게임 `훈련장 1v1`(https://training-1v1.onrender.com)을 Godot 4.7로 옮긴 프로젝트입니다.
Godot에서 이 폴더(`project.godot`)를 열고 **F5**를 누르면 실행돼요.

## 들어간 것

**게임 모드**
- AI 대전 (봇 4단계, 7점 선승, 라운드 150초 · 시간 끝나면 체력 많은 쪽 승리, 라운드마다 진영 바꾸기)
- 친구와 대전 (온라인 1대1 · 2대2 · 3대3 · 4대4 · 개인전 1v1v1v1, 빈자리 AI, 방 코드 R…)
  - 웹 게임의 「학교 와이파이용 방」과 **같은 방식**이라 **웹 게임 친구와 같은 방에서 대전**할 수 있어요 (양방향)
  - 우리 전용 중계 서버(Cloudflare) + 공개 MQTT 서버 5곳에 동시에 연결 — 포트 열기 필요 없음
- 훈련장 (거리별 과녁 10~200m, 움직이는 과녁, 방어구 레벨별 허수아비, 명중률·피해·부위·거리 기록)

**맵 20개** — 원본과 충돌 상자까지 똑같음 (원본 난수 생성기도 그대로 옮겨서 무너진 벽 높이까지 같아요)
- 1대1: 벽돌 골목, 눈 덮인 산장, 사막 마을, 컨테이너 부두 / 2대2: 시골 농장, 돌 유적, 숲 속 캠프, 마을 광장
- 3대3: 공장, 설원 기지, 사막 협곡, 폐허 마을 / 4대4: 훈련장, 도심, 항구, 숲 속 요새
- 개인전: 사거리 광장, 무너진 신전, 눈 덮인 숲속 오두막, 컨테이너 야적장

**총** — 원본 50종 전부 (돌격소총·기관단총·지정사수·저격·산탄·경기관총·권총·석궁), 원본 수치 그대로
- 단발/점사/연사, 노리쇠 장전, 한 발씩 장전, 꺼내는 시간, 산탄, 탄속·총알 낙차·공기저항, 거리별 피해 감소
- 얇은 벽 뚫기(월샷), 저격총 몸샷 규칙, 헬멧·조끼 감소율·내구도·파괴
- 풀파츠: 조준경(아이언~15배율, 3배율 이상은 휠로 배율 조절), 총구(보정기·소염기·소음기·초크·덕빌), 손잡이 6종, 탄창 3종, 개머리판 3종 — 효과 그대로
- 총 고르기 화면 (~): 1·2번 주무기 + 3번 권총, 분류별 목록, 수치 막대, 파츠 고르기와 효과 설명

**움직임** — 서기·앉기·엎드리기(1초 모션), 기울이기, 달리기, 점프, 넘기·올라가기(파쿠르), 계단, 1인칭/3인칭(V), 둘러보기(Alt), 견착(우클릭 길게), 숨 참기(조준 중 Shift)

**투척물** — 세열 수류탄(쿠킹·굴리기·튕김·폭발 피해·이명), 연막탄(봇 시야를 가림), 섬광탄(바라보는 정도만큼 눈부심)

**기타** — 구급상자(6초, +75), 맨손(X), 소리 전부 코드로 합성, 점수판(Tab), 피격 방향, 킬 피드, 라운드 끝 넣은 피해

**설정** — 감도·조준 감도, 우클릭 방식(배그식/토글/누르는 동안), 달리기·앉기·기울이기 방식, **키 바꾸기**, 시야각, 그래픽 품질, 전체화면, 음량, 조준선(5가지 모양 + 직접 만들기: 색·길이·두께·간격·점·테두리·쏘면 벌어짐)

**로그인·친구** — 웹 버전과 같은 Firebase 계정(이메일/비밀번호), 닉네임은 회원 계정에 묶임, 친구 요청·수락·접속 표시는 웹 친구와 이어짐, 친구를 내 방으로 초대(Godot 끼리)

## 웹 버전과 다른 점 (아직 안 옮긴 것)

- 웹의 **일반 방**(코드가 R로 시작하지 않는 방, 브라우저 전용 연결)에는 Godot이 못 들어가요 → 웹에서 「학교 와이파이용 방」으로 만들면 같이 할 수 있어요
- 구글 로그인은 웹에서만 (데스크톱은 이메일/비밀번호)
- 채팅·귓속말, 핑 찍기(F3), 폰 터치 조작, 연결 검사 화면은 아직
- 총·사람 모델은 원본보다 단순한 모양

## 파일

| 파일 | 내용 |
|---|---|
| `scripts/game_data.gd` | 총 50종·파츠·투척물·자세·방어구·봇 수치 |
| `scripts/settings.gd` | 설정·키 설정 저장 (자동 로드 Settings) |
| `scripts/sfx.gd` | 소리 합성 (자동 로드 Sfx) |
| `scripts/world.gd` / `nav.gd` | 맵 만들기 / 봇 길찾기 |
| `scripts/actor.gd` | 플레이어·봇 공통 (총·자세·넘기·투척·피해) |
| `scripts/player.gd` / `bot.gd` / `remote.gd` / `dummy.gd` | 플레이어 / AI / 온라인 상대 / 허수아비 |
| `scripts/combat.gd` | 탄도·월샷·피해·수류탄·연막·섬광·이펙트 |
| `scripts/guns.gd` / `soldier.gd` | 총 모델 / 사람 모델 |
| `scripts/hud.gd` / `menus.gd` | 화면 표시 / 메뉴 |
| `scripts/range.gd` | 훈련장 |
| `scripts/mqtt.gd` / `net.gd` | MQTT 연결 / 온라인 방 |
| `scripts/auth.gd` / `social.gd` | 로그인 / 닉네임·친구 |
| `scripts/main.gd` | 경기 진행 |

## 자동 테스트

```
# AI 대전 한 경기 (플레이어 자동 조준)
Godot_v4.7.2-stable_win64_console.exe --headless --path . --fixed-fps 60 --quit-after 40000 -- --autotest --map=duel --diff=1
# 훈련장
... -- --autotest --range
# 온라인 (창 두 개: 같은 R 코드로) — 방장 옵션: --mpsize=1~4 / --mpffa / --mpbots(빈자리 AI) / --mpmap=맵id
... --max-fps 60 -- --mphost=RT123 --mpsize=2 --mpbots
... --max-fps 60 -- --mpjoin=RT123
# 맵이 웹과 같은지 확인용: 충돌 상자 내보내기
... -- --dumpmaps=maps.json
```
